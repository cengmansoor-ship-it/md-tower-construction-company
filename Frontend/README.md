# Frontend

دا مخکينۍ برخه د React جوړ شوي `dist` څخه د Node.js په ساده server چلېږي.

## چالانول

1. لومړی شا برخه چالانه کړه:

```powershell
cd Backend
npm run dev
```

2. بيا د دې فولډر څخه مخکينۍ برخه چالانه کړه:

```powershell
cd Frontend
npm run dev
```

3. command prompt چې کوم لينک درکړي، لکه `http://localhost:5000`، هماغه خلاص کړه.

يادونه: د عادي کار لپاره `npm install`، `pnpm`، `corepack` او `build` ته اړتيا نشته.
